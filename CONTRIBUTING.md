# Contributing to Argus

Thanks for your interest in contributing to Argus.

## Getting Started

1. Clone the repository
2. Copy `.env.example` to `.env.local` and fill in the required values
3. Run `npm install`
4. Run `npm run dev` to start the development server

## Code Style

This project uses ESLint and Prettier for code formatting. Run `npm run format` before committing to ensure consistent style.

## Pull Requests

- Keep PRs focused on a single change
- Include a clear description of the change and why it's needed
- Ensure `npm run lint` and `npm run format:check` pass before opening a PR
